# Intro to Tailwind CSS

This project is a beginner-friendly demonstration of **Tailwind CSS**.  
It shows how to build simple and responsive web page sections using Tailwind utility classes.

## Project Overview

This project contains multiple HTML files to practice different Tailwind CSS features such as:

- Typography
- Colors and backgrounds
- Spacing
- Borders
- Flexbox
- Grid layout
- Responsive design
- Buttons
- Cards
- Banner section

It is mainly built for learning and practice purposes.

## Files Included

- `index.html` – basic Tailwind CSS practice with text, spacing, flex, grid, and responsive classes
- `banner.html` – a simple responsive banner/hero section
- `card.html` – a card layout using Tailwind CSS
- `images/` – image files used in the project

## Features Used

### 1. Utility Classes
The project uses Tailwind’s utility-first classes for styling directly in HTML.

Examples:
- `text-6xl`
- `bg-green-300`
- `font-bold`
- `underline`
- `p-12`
- `m-4`

### 2. Responsive Design
Responsive breakpoints are used to change layout on different screen sizes.

Examples:
- `md:bg-green-500`
- `lg:bg-yellow-500`
- `md:grid-cols-2`
- `lg:grid-cols-3`

### 3. Flexbox Layout
The project demonstrates how to use Tailwind flex classes to align items.

Examples:
- `flex`
- `justify-center`
- `items-center`

### 4. Grid Layout
Grid is used to create responsive card and box layouts.

Examples:
- `grid`
- `grid-cols-1`
- `md:grid-cols-2`
- `lg:grid-cols-3`
- `gap-4`

### 5. Buttons and Cards
The banner and card pages include styled buttons and reusable card components.

## Technologies Used

- HTML5
- Tailwind CSS (via CDN)

## Tailwind CDN Used

This project uses Tailwind CSS from CDN:

html
<script src="https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4"></script> 

How to Run the Project
Download or extract the project folder
Open the folder in your code editor
Open any of these files in your browser:
index.html
banner.html
card.html

No installation is required because Tailwind CSS is added through CDN.

Learning Outcomes

By completing this project, a beginner can learn:

how Tailwind CSS works
how to style elements using utility classes
how to make responsive layouts
how to create flex and grid sections
how to build simple cards and banners
how to design without writing separate CSS files
Project Purpose

The main goal of this project is to practice Tailwind CSS basics in a simple way.
It is suitable for students and beginners who want to understand modern front-end styling techniques.
